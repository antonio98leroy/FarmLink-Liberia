# FarmLink Liberia

FarmLink Liberia is a direct-to-market agricultural marketplace that helps Liberian farmers and local producers sell products online to households, restaurants, hotels, and retail stores.

## Features

- Product browsing by category and search term
- Pricing in Liberian dollars (LRD)
- Direct order cart and checkout summary
- Buyer-focused sections for households, restaurants, and malls
- Producer network and farm-to-market storytelling
- Mobile-friendly responsive layout

## Run locally

```bash
npm install
npm run dev -- --host 0.0.0.0
```

Then open the local Vite URL shown in the terminal.

## Build for production

```bash
npm run build
```
